# آهنگ‌های پیش‌فرض

⚠️ این مخزن عمومی است: هر آهنگی که اینجا بگذارید برای همه قابل دانلود است (حواستان به کپی‌رایت آهنگ‌های معروف باشد).

هر فایل صوتی (`mp3`, `m4a`, `ogg`, `wav`) که اینجا بگذارید، خودکار به «آهنگ‌های من» در بازی اضافه می‌شود و پخش می‌شود. اسم فایل همان اسم آهنگ در بازی است.
اگر فایلی را پاک کنید، از بازی هم برداشته می‌شود.
