# عکس بازیکن‌های پیش‌فرض

⚠️ این مخزن عمومی است: هر عکسی که اینجا بگذارید برای همه دیده می‌شود، و بعد از پاک کردن هم در تاریخچه‌ی گیت‌هاب می‌ماند.

**قانون:**
- برای هر بازیکن یک پوشه بسازید که اسمش همان اسم بازیکن در بازی باشد (مثلاً `پارسا`).
- داخل پوشه، فایل‌ها به ترتیب اسم خوانده می‌شوند:
  - **عکس اول** (مثلاً `1.jpg`) = عکس اصلی (عکس دایره‌ای بالای صفحه). بهتر است عکس از سر و شانه باشد؛ بازی خودش وسطِ بالای عکس را مربع می‌بُرد.
  - **عکس دوم** (مثلاً `2.jpg`) = عکس شادی، که بعد از هر جواب درست بزرگ نشان داده می‌شود.
- اگر بازیکنی با آن اسم در بازی نباشد، خودش ساخته می‌شود.
- اگر روی گوشی برای بازیکن عکس دیگری انتخاب کنید، عکسِ روی گوشی برنده است.

نمونه:
```
photos/پارسا/1.jpg
photos/پارسا/2.jpg
```
